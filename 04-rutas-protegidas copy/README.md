# REACT ROUTER DOM

## Objetivos

Implementar la navegacion a traves de rutas protegidas

## Descripcion

1. Home (/) -> Página pública con botón de Login
2. Perfil (/profile) -> Página protegida con información del usuario
3. Dashboard (/dashboard) -> Página protegida con estadísticas

## Requisitos

1. Vite
2. React Router Dom v7
3. Simular uso de un token que valide el login guardando en localStorage
4. Página de errores gestionados por nosotros
