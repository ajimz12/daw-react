# Proyecto de Pokemon con uso de React Router v7

Se pretende crear un proyecto que va a utilizar las siguientes tecnologías:

- React Router Dom versión 7
- Contextos globales
- Libreria Sonner para notificaciones
- Estilado con Tailwind CSS

**El scaffolding a utilizar será el siguiente:**

```text
src/
├─ components/
│  ├─ NavBar.jsx
│
├─ context/
│  ├─ PokemonContext.jsx
│
├─ layout/
│  ├─ RootLayout.jsx
│
├─ pages/
│  ├─ Home.jsx
│  ├─ Search.jsx
│  ├─ PokemonDetail.jsx
│  ├─ Favorites.jsx
│
├─ routes/
│  ├─ Router.jsx
│  ├─ paths.js
│
├─ App.jsx
├─ main.jsx
```

**2. Componentes**
